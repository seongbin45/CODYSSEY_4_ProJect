# 나만의 프롬프트 관리 프로그램

터미널에서 메뉴 번호를 입력해 프롬프트를 등록·조회·검색·즐겨찾기할 수 있는 콘솔 기반 Python 프로그램입니다.
외부 라이브러리 없이 기본 문법만으로 구현했습니다.

## 실행 방법

```bash
python main.py
```

Python 3.10 이상이 필요합니다.

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목/내용/카테고리를 입력해 새 프롬프트 등록 |
| 2 | 프롬프트 목록 | 전체 프롬프트를 번호와 함께 출력 |
| 3 | 카테고리별 조회 | 선택한 카테고리의 프롬프트만 출력 |
| 4 | 프롬프트 검색 | 제목/내용에 포함된 키워드로 검색 |
| 5 | 프롬프트 상세 보기 | 번호 입력 시 전체 내용 출력 (조회수 기록) |
| 6 | 즐겨찾기 관리 | 프롬프트를 즐겨찾기에 추가/해제 |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아보기 |
| 8 | 프롬프트 수정/삭제 | 기존 프롬프트 편집 또는 삭제 (보너스) |
| 9 | 조회수 Top 목록 | 상세 보기 조회수 기준 정렬 (보너스) |
| 10 | JSON으로 저장 | 현재 프롬프트를 `prompts.json`으로 저장 (보너스) |
| 11 | JSON에서 불러오기 | `prompts.json`을 읽어 데이터 복원 (보너스) |
| 12 | Markdown 내보내기 | 카테고리별로 `exports/카테고리.md` 생성 (보너스) |
| 0 | 종료 | 프로그램 종료 |

실행 중 데이터는 메모리에만 유지됩니다. 메뉴 10번으로 JSON 영속 저장이 가능합니다.
